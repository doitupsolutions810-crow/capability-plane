# Full tree

GitHub holds the core plane modules, config, docs, scripts, attestpipe bus, floci stubs.

Complete sources including `plane_service/server.py`, `gateway/*`, OpenAPI, Control12 adapter, and runtime pipeline are in the local release zip built alongside this repo:

- `capability-plane-fullstack.zip`
- `capability-plane-release/`

Clone this repo and overlay from the zip if any large module is missing from `main`.

Private signing key is never committed.
